# Zeta Zeta League History

The all-time history of the Zeta Zeta fantasy football league (ESPN, 2013 to today), as a single page.
Every number comes from ESPN and lives in the league's Google Sheet; this page reads that Sheet live
and falls back to the saved copies in `data/` if the Sheet does not answer.

Built 11/16/26. Updated automatically every week during the season.
